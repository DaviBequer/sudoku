# Sudoku

Sudoku minimalista que roda no navegador e pode ser instalado no celular (PWA).

- Desafios 9×9, 16×16 e 25×25 em três níveis, com progresso salvo
- Rascunho com limpeza automática opcional
- Dicas discretas: explicação do raciocínio ou revelar um número
- Importa um sudoku a partir de uma foto, ignorando anotações à mão

Abra pelo GitHub Pages e use "Adicionar à tela inicial" / "Instalar app".
